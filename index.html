简洁明了的项目配置:



        //pizza.json
{
    "name": "项目名称",
    "version": "版本",
    "desc": "描述",
    "author": "作者名称",
    "email": "邮箱",
    "main": "src/main.py:main", //文件:入口点
    "deps": [], //依赖
    "scripts": {}, //自定义脚本(pizza <name>)
    "build": { //编译选项
        "icon": null, //图标
        "console": true, //是否显示终端
        "skip": false //是否跳过依赖安装错误
    }
}

参数
    -i 设置编译文件的图标       -g 设置编译后的可执行文件是否有控制台

    -s 设置依赖安装失败时是否跳过       -- run项目/文件时传递参数


其它命令
clean 一键清理 freeze 保存依赖到文件 add 添加依赖 remove 删除依赖 set 设置并覆盖依赖
